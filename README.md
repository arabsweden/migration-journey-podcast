# محلل رحلات الهجرة — بودكاست الذكاء الاصطناعي

تطبيق RAED SHIHAB لتحليل قصص الهجرة وإنشاء حوار بودكاست.

المصدر: https://ai.studio/apps/86f10d3e-3ab4-48f6-826d-3ddea1e643c1

## النسخة العامة

https://arabsweden.github.io/migration-journey-podcast/

الواجهة تعمل على GitHub Pages. التحليل والتفريغ والترجمة وتوليد الصوت تحتاج خدمة Gemini آمنة على خادم؛ لم تُفعّل في هذه النسخة. لا تضع مفتاح Gemini في GitHub أو في ملفات المتصفح. ملف .env.local الأصلي لم يُرفع.

## تشغيل الواجهة محلياً

Node.js 22 أو أحدث:

```sh
npm install
npm run dev
```

## النشر

GitHub Actions يبني الواجهة وينشرها إلى Pages عند تحديث main. اختر GitHub Actions كمصدر النشر في Settings → Pages.

المحتوى والتحليلات المولّدة تحتاج مراجعة بشرية والتحقق من المصادر الرسمية قبل استخدامها لاتخاذ قرارات قانونية.
